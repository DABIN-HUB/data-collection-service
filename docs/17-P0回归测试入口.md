# P0 回归测试入口

## 1. 目标

固定当前 P0 改造后的最小回归入口，避免每次手工拼接 `-Dtest=...` 参数。

## 2. 固定 Suite

测试套件：

- `src/test/java/com/wangbin/collector/regression/P0RegressionSuite.java`

当前纳入的测试类：

1. `CollectorDataPostProcessorTest`
2. `CollectionSchedulerTest`
3. `CacheReportServiceTest`
4. `TelemetryStreamServiceImplTest`
5. `ShadowManagerTest`

## 3. 固定执行方式

Maven profile：

- `p0-regression`

执行命令：

```bash
mvn -q -Pp0-regression test
```

## 4. 维护规则

1. 新增 P0 定向测试后，同步加入 `P0RegressionSuite`。
2. 如果某个测试上升为主链路关键回归，优先纳入该 suite，而不是继续堆叠命令行 `-Dtest`。
3. 默认 `mvn test` 保持全量测试行为，`p0-regression` 只负责固定的 P0 回归入口。
