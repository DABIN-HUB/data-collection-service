# IEC61850

## 实现类

- `core/collector/protocol/iec/Iec61850Collector`
- 基类：`core/collector/protocol/iec/base/AbstractIec61850Collector`

## 实现方式

- 基于 `iec61850bean` 进行读写、模型操作、报告处理。
- 支持命令：`read/write/select/operate/reload_model`。

## 地址与点位配置

- 地址可写成 `对象引用@FC` 或 `对象引用:FC`。
- 也可在 `additionalConfig` 组合：`logicalDevice/logicalNode/dataObject/dataAttribute/subAttribute/fc`。

## 使用方式

1. 设备 `protocolType` 设为 `IEC61850`。
2. 配置 MMS 连接参数（host/port/timeout）。
3. 点位填写对象引用与 FC（如 ST/MX/CO）。
