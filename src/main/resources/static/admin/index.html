手动写点位

使用示例

先选择设备，再把左侧 key 改成真实点位标识；支持 pointId、pointCode、pointName、pointAlias、reportField。被写入的点位必须配置为可写，否则后端会返回失败。

{
  "values": {
    "temperatureSet": 25,
    "switchEnable": true
  }
}

执行命令

CollectionManager.executeCommand
使用示例

先选择设备，再填写采集器支持的命令名和参数。不是所有协议都支持同一组命令；不支持的命令可能返回失败或空结果。

{
  "command": "readRaw",
  "params": {
    "address": "40001",
    "dataType": "INT16"
  }
}
